Instruction Format

Every instruction is 12 bits.

The decoder splits opcode, registers, immediate values, and jump addresses from the instruction bus.

I(11 downto 10)Opcode
I(9 downto 7)RegA
I(6 downto 4)RegB
I(3 downto 0)Immediate value
I(2 downto 0)Jump address for JZR
Instruction Set

The current datapath supports four main operations.

Special encodings for absolute difference and multiplication are documented in Instruction.txt and appear in the advanced source set.

00 ADDRegA gets RegA + RegB
01 SUB/NEGAdder/subtractor subtraction mode
10 MOVIRegA gets immediate value
11 JZRJump when selected register is zero
Program ROM

The current program calculates 1 + 2 + 3.

Edit components/program-rom/Program_Rom.vhd to change the instruction sequence.

"100010000001", -- 0: Movi R1, 1
"100100000010", -- 1: Movi R2, 2
"001110010000", -- 2: Add  R7, R1
"001110100000", -- 3: Add  R7, R2
"100110000011", -- 4: Movi R3, 3
"001110110000", -- 5: Add  R7, R3
"100010000000", -- 6: Movi R1, 0
"110000000111"  -- 7: JZR  R0, 7
Expected Result

R7 is the visible result register.

After the ROM program runs, R7 = 0110, which is decimal 6. That value is exposed through the `Reg` output and seven-segment display path.

Advanced Folder

Use Nano_Processor_advanced/srcs_1, sim_1, and constrn_1 together when creating a separate Vivado project.
